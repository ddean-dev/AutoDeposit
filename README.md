# AutoDeposit
A World of Warcraft addon for automatically depositing and withdrawing gold from your warband bank.

## Installation
Copy the GitHub URL into WoWUp

## Building Locally
- install git modules
- create `.env` file with your wow addons folder set
```bash
WOW_ADDONS_FOLDER="~/Games/battlenet/drive_c/Program Files (x86)/World of Warcraft/retail/Interface/AddOns/"
```
- run `bash build.sh`
